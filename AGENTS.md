# Madhav's Portfolio Project Guidelines

## Aesthetic & Tone
- Theme: Minimal, high-tech dark mode ("From Assembly to React").
- Target Audience: CS Recruiters & Engineering Managers.
- Tech Stack: React, Vite, CSS.

## Project Workflow
- Dev Server: `npm run dev`
- Build Check: `npm run build`
- Always verify mobile responsiveness and linting before committing code.
